        How designing works
        1. Drag an effect onto the keyboard above to light every key with it.
        2. Drag a reaction onto the keyboard to choose how a key answers when it is pressed. Click a key above to try it.
        3. Drag a colour onto a key to paint just that key, or hold Shift as you drop to paint its whole group. Drop one on a group's name below, on the light bar along the top, or on the keyboard's background to light every key that colour.
        4. Set the pace and brightness with the sliders. Everything you do is written into the text below, which you can also edit by hand.
        5. Pick where to save it and press Save. Saved to this profile, it shows only on this profile; saved to its theme, on every profile that uses the theme.

        Pressed keys only light up once key reports are turned on; see docs/keyboard-lighting.md in the daemon's repository.

          galdeck calibrate

          Panel probe

          Draws a bordered square on every key at a chosen size. If the yellow border sits flush with the physical keycap, that size is right; if anything shows outside it, the image is too small for the panel. This is a diagnostic, so it stays up until you put the page back.
